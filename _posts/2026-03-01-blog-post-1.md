Данный пост был мотивирован первым занятием семинара Ольги Вениаминовны Кунаковской, посвященным двухсот летию доклада Николая Лобачевского 
"Сжатое изложение начал геометрии". Дата выступления Лобачевского с этим докладом - 23 февраля 1826 года, и именно оно дало начало 
неевклидовой геометрии. 

В данном посте будет изложен неочевидный факт: если в линейном векторном пространстве \\(\mathbb{C}^n\\) заменить комплексное поле, относительно 
которого определяется пространство, на вещественное, то размерность пространства удваивается! 

## Предварительные сведения

Для формулировки основных идей вспомним некоторые простые определения из алгебры. Во-первых, **полем** мы называем множество \\(F\\) некоторых элементов
с введенными операциями сложения и умножение, удовлетворяющими следующим аксиомам:
1. Коммутативность сложения: \\( \forall a, b \in F: \ a+b = b+a\\).
2. Ассоциативность сложения: \\( \forall a, b, c \in F: \ (a+b)+c = a+(b+c) \\).
3. Существование нулевого элемента: \\( \exists 0 \in F: \ \forall a \in F \ a+0 = a\\).
4. Существование противоположного элемента: \\( \forall a \in F \ \exists (-a) \in F: \ a+(-a) = 0\\).
5. Коммутативность умножения: \\( \forall a, b \in F: \ a * b = b * a \\).
6. Ассоциативность умножения: \\( \forall a, b, c \in F: \ (a * b) * c = a * (b * c) \\).
7. Существование единичного элемента \\(\exists e \in F: \ \forall a \in F \ a * e = a \\).
8. Существование обратного элемента для ненулевых элементов: \\( \forall a \in F: \ a \neq 0 \ \exists a^{-1} \in F: \ a * a^{-1} = e \\).
9. Дистрибутивность умножения относительно сложения: \\( \forall a, b, c \in F: \ (a+b) * c = (a * c) + (b * c) \\).

Более магическим языком, поле - это алгебра над множеством \\(F\\), образующая коммутативную группу по сложению и коммутативную группу по умножению.
Примерами полей могут служить такие привычные множества, как множества рациональных, вещественных или комплексных чисел. Или, например, поля рациональных
функций и поля вычетов по модулю простого числа. 

Не перечисляя снова привычных аксиом, скажем, что **линейным пространством \\(L\\) над полем \\(F\\)** называется такое множество векторов \\(L\\), где определены
операции сложения: \\(\forall x, y \in L: \ x+y \in L \\) и умножения вектора на элемент поля: \\(\forall \lambda \in F, \ \forall x \in L: \ \lambda x \in L\\).

В любом линейном пространстве выделяют некоторую группу особенных векторов, называемых **базисом** пространства - это такой набор векторов из \\(L\\),
что любой другой вектор этого пространства может быть единственным образом представлен в виде линейной комбинации векторов из этого набора.

**Размерность линейного пространства** \\(L\\) - это просто количество базисных векторов. Это число обозначается \\(\dim L\\). 

## Примеры линейных пространств

* Пространство \\( \mathbb{R}^n \\).

Любой \\(x \in \mathbb{R}^n \\) - это упорядоченный набор \\(x = (x_1, x_2, \dots, x_n), \ x_k \in \mathbb{R}, \ k = 1, 2, \dots, n. \\) В этом случае 
каждый вектор \\(x\\) представим в виде
\\[
x = x_1(1, 0, \dots, 0) + x_2(0, 1, \dots, 0) + \dots + x_n(0, 0, \dots, 1).
\\]
Таким образом, базис линейного пространства \\( L = \mathbb{R}^n \\) состоит из векторов
\\[e_1 = (1, 0, \dots, 0),\\]
\\[e_2 = (0, 1, \dots, 0),\\]
\\[\cdots\\]
\\[e_n = (0, 0, \dots, 1).\\]
Таких векторов \\(n\\) штук, откуда заключаем, что \\(\dim\mathbb{R}^n = n\\).

Отметим, что по другому, эквивалетному, определению базиса - это максимальная линейно независимая система векторов из данного пространства.
В нашем примере легко убедиться, составив матрицу, где каждый столбец - это вектор \\(e_k\\), что данная система действительно лин. независима
(определитель составленной матрицы отличен от нуля). 

* Пространство \\( \mathbb{C}^n \\). 

Рассмотрим теперь пространство над полем \\(\mathbb{C}\\) из векторов, где компоненты - комплексные числа. То есть 
\\[
z = (z_1, z_2, \dots, z_n), \ \ z_k \in \mathbb{C}, \ k=1, 2, \dots, n.
\\]
Полностью аналогичными рассуждениями, что были даны в первом примере, приходим к тому, что это пространство имеет размерность \\(n\\).

* Пространство \\( \mathbb{C}^n \\) над полем \\(\mathbb{R}\\).

Данный далее пример служит основным рассуждением в этом посте. Рассмотрим, как и выше, векторы с комплексными компонентами, то есть \\(L = \mathbb{C}^n\\),
но сделаем небольшое ограничение - разрешим умножать векторы лишь на вещественные числа, то есть положим в качестве поля в определении линейного
пространства: \\(F = \mathbb{R}\\). Что изменится в этом случае? 

Каждый вектор \\(z \in \mathbb{C}^n\\) представим в виде

\\[ z = (z_1, z_2, \dots, z_n) = (a_1+b_1 i + a_2 + b_2 i, \dots, a_n+b_n i) = \\]
\\[ = (a_1, a_2, \dots, a_n) + (b_1 i, b_2 i, \dots, b_n i), \ a_k, b_k \in \mathbb{R}.\\]
Откуда любой вектор \\(z \in \mathbb{C}^n\\) представим в виде
\\[z = a_1(1, 0, \dots, 0) + a_2(0, 1, \dots, 0) + \dots + a_n(0, 0, \dots, 1)+ \\]
\\[+ b_1(i, 0, \dots, 0) + b_2(0, i, \dots, 0) + \dots + b_n(0, 0, \dots, i).\\] 

Это означает, что размерность пространства удвоилась! Теперь базисный набор векторов выглядит следующим образом:
\\[e_1 = (1, 0, \dots, 0),\\]
\\[e_2 = (0, 1, \dots, 0),\\]
\\[\cdots\\]
\\[e_n = (0, 0, \dots, 1),\\]
\\[f_1 = (i, 0, \dots, 0),\\]
\\[f_2 = (0, i, \dots, 0),\\]
\\[\cdots\\]
\\[f_n = (0, 0, \dots, i).\\]
В связи с этим наблюдением, часто при указании размерности пространства указывают также, относительно какого поля определенно пространство, то есть
\\[\dim_{\mathbb{C}}\mathbb{C}^n = n, \quad \dim_{\mathbb{R}}\mathbb{C}^n = 2n. \\]
 

## Заключение

В заключении хочется отметить, что удвоение размерности при переходе от комплексного поля к вещественному полю проявляется не только в этих простых примерах,
но и в различных нелинейных топологических пространствах, где это свойство менее очевидно, но оно приводит ко многих замечательным результатам, о которых,
возможно, будет написано в будущем. 

Даже в случае линейных пространств с понятием размерности связаны многие интересные утверждения. Пусть \\(A\\) - оператор в векторном пространстве
\\(L\\). **Образом** оператора называется множество всех тех векторов, куда мы можем попасть при действии оператора \\(A\\), то есть
\\[\operatorname{Im} A = \\{y \in L: \ \exists x: \ A(x) = y\\}. \\]
**Ядром** оператора называется множество всех тех векторов, которых оператор переводит в ноль, то есть
\\[ \operatorname{Ker} A =  \\{x \in L: \ A(x) = 0 \\}. \\]
Оказывается, образ и ядро оператора являются пространствами. Размерность образа называют рангом, а размерность ядра - дефектом, и существует теорема
о ранге и дефекте, утверждающая следующее:

*Если \\(L\\) - линейное пространство, \\(A\\) - некоторый оператор в нем, то*  
\\[\dim \operatorname{Im} A + \dim \operatorname{Ker} A = \dim L. \\] 

Более того, существует понятие дробной размерности для, так называемых,
фрактальных множеств. По-мимо этого, в примерах линейных пространств мы рассматривали векторы, составленные лишь из вещественных и комплексных чисел, но существуют
и более причудливые числовые системы, такие как кватерионы и октавы, о которых можно подробно почитать в небольшой книге И. Л. Кантора, А. С. Солодовникова: 
"Гиперкомплексные числа".
